# Bright Coffee Shop Sales Analysis

SQL data cleaning and analysis of coffee shop sales for the BrightLearn case study.

## 1. Project Description
This project analyzes transactional sales data from Bright Coffee Shop to help the CEO understand revenue drivers, peak sales times, and product performance. See `project_description/` for the case study brief and raw dataset.

## 2. Project Planning
Data flow and architecture planning done in Miro, outlining data source, ETL process, storage, and analysis steps. See `project_planning/`.

## 3. Data Processing
Data cleaning and transformation performed using SQL in Databricks (creating time buckets, day names, and total revenue calculations), then exported to Excel for pivot tables and charts. See `sql/` and `excel/`.

## 4. Presentation & Visualization
Dashboards built in Power BI, Google Data Studio, and Lovable, plus a final PowerPoint presentation summarizing key insights and recommendations. See `visualizations/` and `presentation/`.
